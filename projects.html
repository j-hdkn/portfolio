Multisite Network Architecture with Dynamic Multipoint VPN (DMVPN)

Cisco IOS • DMVPN • IPsec • GNS3 • Routing

Bachelor’s Thesis Project
Supervised by Ing. Victor OYETOLA
Designed and implemented a scalable, secure multisite enterprise network topology utilizing Dynamic Multipoint VPN (DMVPN) with IPsec encryption. Configured dynamic routing over encrypted tunnels to ensure seamless inter-site communication, reduced overlay latency, and optimized WAN infrastructure setup.

Corporate Network Infrastructure & Security Audit

Debian 13 • IPv4/IPv6 • DHCP • NFS/Samba/SFTP • iptables • OpenSSH • nmap

Academic Practical Project (ULCO / EILCO)
Supervised by M. Guillaume Mantez
Designed and secured a virtualized enterprise network infrastructure (SARL Numeryo). Configured persistent dual-stack IPv4/IPv6 addressing, deployed ISC DHCP server, and implemented cross-department file-sharing services (NFS with root_squash, Samba, SFTP). Hardened server security via restrictive stateful iptables firewall rules, SSH key-based authentication (RSA 4096), and performed post-deployment security auditing using nmap.
